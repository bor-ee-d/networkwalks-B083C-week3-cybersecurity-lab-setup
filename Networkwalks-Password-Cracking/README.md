# W3-PM2 — Password Cracking with Networkwalks Tools

## Objective

Use the Networkwalks **Hash Calculator** and **Password Cracker** to recover the password of the protected PDF supplied for the Week 3 lab.

## Workflow

1. Download the encrypted PDF supplied for the lab.
2. Upload it to the Networkwalks Hash Calculator.
3. Copy the complete hash beginning with `$pdf$`.
4. Open the Networkwalks Password Cracker.
5. Paste the hash and start the attack.
6. Wait for the tool to finish and display the recovered password.
7. Enter the recovered password into the locked PDF.

## Learning Outcome

The exercise demonstrates a browser-based password-cracking workflow: obtain the hash from a protected file, provide the hash to the cracking tool, recover the password, and verify it by opening the protected PDF.
